# Sprint 3 — Solicitudes

## Meta del Sprint

**Objetivo:** Implementar flujo completo de solicitudes con documentos

**Fecha de inicio:** 2026-08-20
**Fecha de fin:** 2026-08-27
**Duración:** 2 semanas

## Resultado Esperado

- Creación de solicitudes funcionando
- Perfil académico y financiero del postulante
- Upload y gestión de documentos
- Checklist de documentos completo
- Envío de solicitud con máquina de estados
- US-13 (opción "otro") aplicada a los perfiles de solicitud

## Criterios de Aceptación

- [x] Postulante puede crear solicitud vinculada a convocatoria
- [x] Perfil académico guarda información del estudiante (incluye campos "otro" US-13)
- [x] Perfil financiero registra datos económicos
- [x] Documentos se pueden subir, quitar y reemplazar (PDF/JPG/PNG ≤ 5 MB)
- [x] Checklist muestra estado de documentos requeridos
- [x] Solicitud cambia de estado al enviarse (máquina de estados + historial)
- [x] Envío validado: bloquea si faltan perfiles o documentos obligatorios
